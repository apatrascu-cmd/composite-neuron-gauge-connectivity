# Version 1.0.0

This release accompanies the corrected journal revision. It includes:

- synchronous agent-based updates aligned with the methods;
- coverage-aware transported coherence;
- reciprocal and complete fundamental-cycle diagnostics;
- exact static covariance and offset-compensator controls;
- frozen-transporter and smaller-step negative controls;
- fixed-point, memory-kernel and exact-pole cluster elimination;
- final-epoch CIFAR-10 records with inference and trainable parameter counts;
- generated tables, figures and a checksum manifest;
- held-out hierarchical promotion with matched information-only, random-link and oracle controls;
- a label-free scale selector and complete-cycle certification at the promoted scale;
- a capacity- and initialisation-matched interpolation between non-invariant and invariant phase read-outs, with paired fingerprints for every seed.

Superseded exploratory results and earlier manuscript versions are intentionally excluded.
